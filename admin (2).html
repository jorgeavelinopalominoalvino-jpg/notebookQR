🌱 Contenido de ejemplo

Si la base de datos está vacía, podés cargar de un solo click las materias y temas de ejemplo del proyecto original (Inglés, CCSS y Matemáticas).

➕ Agregar materia

Una materia agrupa los temas (por ejemplo: Inglés, Comunicación, Ciencia y Tecnología).

📎 Agregar tema

Un tema es una clase puntual: título, descripción y el video o imagen que la explica.

📌 Para video: pegá el link normal de YouTube (ej: youtube.com/watch?v=... o youtu.be/...) o el link para compartir de Google Drive (con acceso "Cualquiera con el enlace"). Para imagen: subila a algún servicio con enlace público (Google Drive, Imgur, etc.) y pegá ese link.

📌 Asignar tarea

Esto es lo que van a ver los alumnos como "pendiente" en la página principal. No hace falta que ellos carguen nada.
